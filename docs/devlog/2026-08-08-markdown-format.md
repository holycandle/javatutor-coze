# 2026-08-08 — Markdown 格式规范化

## 背景
Agent 输出的 Markdown 格式损坏：标题 `###` 后无空格、分隔线 `---` 与文字粘连、代码块挤在一行，导致前端渲染为单个 `<p>` 标签。

## 分析
根因是模型在生成 Markdown 时省略了必要的空格和换行，四个专家节点都有此问题，需要同时从 Prompt 约束和代码后处理两个层面修复。

## 修复

### 1. Prompt 层约束
四个专家 system prompt 末尾追加硬性格式规范：
- `###` 与文字之间必须有空格，标题前后空行
- `---` 分隔线独占一行，前后空行
- 代码块 ```java 后换行，代码逐行，``` 前换行
- 列表 `-` 后空格，列表项间换行
- 段落之间空行分隔

### 2. 代码层兜底
`_normalize_md()` 后处理函数，强制修复：
- `###` 后无空格 → 正则补空格
- 代码块围栏后紧跟代码 → 插换行
- `---` 与文字粘连 → 前后插换行

### 3. 验收
三次 `/stream_run` 验证，输出正确渲染为 `<h3>`、`<pre>`、`<ul>`、`<p>` 块，不再是单个超长 `<p>`。
