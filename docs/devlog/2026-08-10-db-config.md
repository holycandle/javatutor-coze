# 2026-08-10 — 数据库配置与 RAG 修复

## 背景
Coze 平台提供了 `DATABASE_URL` 环境变量（Neon PostgreSQL），此前 `PGDATABASE_URL` 未配置导致服务启动时 `get_engine()` 失败。

## 配置
- 创建 `.env` 文件写入 `PGDATABASE_URL`（含 SSL 连接参数 `sslmode=require`）
- `db.py` 通过 `load_dotenv()` 自动加载
- 保留 SQLite 兜底引擎作为安全网

## 修复

### 1. EmbeddingClient API 适配
`embed_texts()` 返回扁平 `list[float]`（单向量），不是预期的 `list[list[float]]`，改为逐条调用 `embed_text()` 获取每个文本的独立向量。

### 2. pgvector 类型转换
psycopg 无法直接将 Python `list[float]` cast 为 `vector` 类型。新增 `_vector_to_str()` 将列表转为 `"[0.1,0.2,...]"` 字符串格式。

## 验证
- 10 条知识分块成功导入（5 条编译错误 + 5 条标准库）
- RAG 检索验证：搜索 "Java array index out of bounds" → 命中 ArrayIndexOutOfBoundsException (score=0.757)
- 81/81 测试通过，test_run 端到端验证通过
